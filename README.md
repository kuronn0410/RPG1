# DECKRPG

## 概要

カードによる能力強化と武器を活用して、複数のステージを攻略する3DアクションRPGです。  
町でカードや武器を購入・編成し、敵を倒してレベルを上げながら、最終ステージのボス撃破を目指します。

## 起動方法

1. 配布フォルダを展開します。
2. フォルダ内の `RPG1.exe` を起動します。
3. タイトル画面から「はじめから」または「つづきから」を選択します。

## 操作方法

| 操作 | キー |
|---|---|
| 移動 | W / A / S / D |
| 視点操作 | マウス移動 |
| 攻撃 | マウス左クリック |
| UI・ワールドボタン操作 | マウス左クリック |
| カード使用 | 数字キー 1～5 |
| インベントリ表示 | B |

町ではカード編成や武器変更、ショップの利用ができます。  
戦闘ステージでは、画面に表示されるガイドに従って敵を倒してください。
